# 夢時商業股份有限公司 ウェブサイト要件定義書

## プロジェクト概要
「夢時商業股份有限公司」は台湾で1対1の個別指導教育サービスを提供する企業です。本プロジェクトでは、同社の公式ウェブサイトを開発し、台湾在住の小学生から高校生（および大学生、社会人）に対して教育サービスの情報提供、問い合わせ獲得、体験授業の申し込みを促進することを目的としています。

## 目標とゴール
1. 会社および教育サービスの情報を明確に伝える
2. 校舎の情報と特徴を詳細に紹介する
3. 問い合わせおよび体験授業の申し込みを獲得する
4. 繁体字中国語、英語、日本語の3言語対応によるアクセシビリティ向上

## ターゲットユーザー
- **主要ターゲット**: 台湾在住の台湾人で小学生から高校生およびその保護者
- **セカンダリターゲット**: 台湾在住の大学生、社会人

## 機能要件

### コア機能
1. **多言語対応**
   - 繁体字中国語（最優先）
   - 英語
   - 日本語
   - 言語切替機能

2. **レスポンシブデザイン**
   - モバイル、タブレット、デスクトップ対応

3. **ナビゲーション**
   - ヘッダーメニュー（PC用）
   - ハンバーガーメニュー（モバイル用）

4. **情報表示**
   - 会社概要
   - 教育サービス情報
   - 校舎情報
   - 講師紹介
   - お知らせ・ニュース

5. **問い合わせ・申し込み**
   - お問い合わせフォーム
   - 体験授業申し込みフォーム

### 追加機能
1. **画像ギャラリー**
   - 校舎の写真表示
   - 拡大表示機能

2. **マップ表示**
   - 校舎位置のGoogle Map埋め込み

3. **ソーシャルメディア連携**
   - SNSアイコン・リンク

## 非機能要件
1. **パフォーマンス**
   - ページロード時間の最適化
   - 画像の最適化

2. **セキュリティ**
   - お問い合わせフォームのセキュリティ対策
   - SSL対応

3. **保守性**
   - コンテンツ更新の容易さ
   - モダンな技術スタックの採用

## ページリスト

1. **ホームページ (index.html)**
   - **説明**: サイトのメインページ、会社とサービスの概要紹介
   - **主要機能**:
     - ヒーローセクション（キャッチコピーと体験授業CTA）
     - 教育サービスの特徴紹介
     - 校舎の簡易紹介（詳細ページへのリンク）
     - 新着ニュース・お知らせ
     - 日本の兄弟会社の紹介

2. **校舎紹介ページ (schools.html)**
   - **説明**: 校舎の詳細情報を提供するページ
   - **主要機能**:
     - 各校舎の詳細情報（住所、電話番号、特徴）
     - 写真ギャラリー
     - 営業時間
     - アクセス情報
     - 地図表示
     - 見学予約・問い合わせリンク

3. **コース紹介ページ (courses.html)**
   - **説明**: 提供するコースやサービスの詳細
   - **主要機能**:
     - 各教科・コースの説明
     - 対象年齢層
     - 授業料情報
     - コースの特徴
     - 体験授業の案内

4. **講師紹介ページ (teachers.html)**
   - **説明**: 教師陣の紹介
   - **主要機能**:
     - 講師のプロフィール
     - 専門分野
     - 経歴
     - 写真

5. **お問い合わせページ (contact.html)**
   - **説明**: 問い合わせと体験授業申し込みのためのページ
   - **主要機能**:
     - 問い合わせフォーム
     - 体験授業申し込みフォーム
     - 校舎の連絡先情報
     - FAQ

6. **ブログ/教育コラムページ (blog.html)**
   - **説明**: 教育関連の記事や最新情報を提供
   - **主要機能**:
     - 教育関連の記事一覧
     - カテゴリ分類
     - 記事検索

7. **会社概要ページ (about.html)**
   - **説明**: 会社の詳細情報
   - **主要機能**:
     - 会社の歴史・理念
     - ビジョン・ミッション
     - 日本の兄弟会社について
     - 会社情報（設立年、代表者など）

## データモデル
1. **校舎情報**
   - 名前
   - 住所
   - 電話番号
   - 特徴
   - 営業時間
   - アクセス方法
   - 地図URL
   - 写真

2. **コース情報**
   - コース名
   - 対象年齢/学年
   - 内容説明
   - 特徴
   - 料金情報

3. **講師情報**
   - 名前
   - 専門分野
   - 経歴
   - 写真

4. **ニュース/お知らせ**
   - タイトル
   - 日付
   - 内容
   - カテゴリ
   - 画像

## 技術スタック
- **フロントエンド**: HTML5, CSS3, JavaScript, React
- **UIフレームワーク**: Material UI
- **レスポンシブデザイン**: Flexbox, Grid, Media Queries
- **多言語対応**: React i18n または類似のライブラリ
- **マップ連携**: Google Maps API
- **フォーム処理**: サーバーサイド処理またはFormspree等のサービス

## 制約条件
- 繁体字中国語が最優先言語
- モバイルファーストの設計
- 画像やコンテンツは夢時商業股份有限公司から提供
- 既存のブランドカラー（ゴールド: #d4af37, ダークグレー: #1a1a1a）を使用
